# NPC 지식과 주장 기록

`memory.py`는 NPC별 `facts`, `claims`, `episodes`를 내부 상태의 `npc_knowledge`에 유지한다.
기본 사실은 시나리오에서 생성하고, 주장에는 `source=player_assertion`, `verified=false`와
NPC 반응 `believed/doubted`를 기록한다. 믿는다는 판정은 세계의 사실을 생성하지 않는다.
장부는 snapshot에도 보존되지만 공개 API에서는 제외된다.

현재 사회 판정은 하를란에게 시장의 사절이라고 주장하는 한 가지 시나리오다.
서버 d20+deception_bonus(기본 3)와 DC14를 비교해 성향을 trusting/suspicious로 변경한다.
새 증거 없이 같은 주장을 반복하면 이전 판단을 유지하며 재굴림하지 않는다.
판정에는 1분이 들고, 하를란이 없는 장소나 전투 중에는 거부한다.

NPC 대화의 모델 입력은 해당 화자의 공개 가능한 사실·미검증 주장·최근 접촉만 포함한다.
고정 행동 버튼은 확정된 시나리오 문장을 사용하며, 모델로 해석된 자유문장 대화는
동일 narrator adapter에 화자 역할과 전용 지식을 전달해 발화를 생성한다.
생성 문장이 지식과 모순되는지에 대한 의미적 검증과 실제 공급자 품질 평가는 아직 필요하다.

최근 접촉은 20개, 모델 전달 접촉은 6개로 제한한다. 사실과 중요 주장은 별도 장부에 남겨
최근 접촉에서 밀려나도 유지된다. 게임시간 120분 이동 및 접촉 100회 후 주장 보존을
자동 검사한다. 이는 실제 2시간 플레이나 폭넓은 장기 기억 품질 통과를 의미하지 않는다.

후속 범위: 임의 주장의 추출·증거·반증, 사실의 만료/갱신, 사건별 목격자 전파,
의미 검색과 요약, NPC 비공개 지식 공개 정책, 다양한 설득·협박·기만 시나리오.
