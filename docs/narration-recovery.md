# 확정된 턴의 서사 복구

판정과 서사는 별도 단계다. 판정이 저장된 뒤 프로세스가 종료되거나 AI가 실패해도
주사위·시간·보상·이벤트·캠페인 버전은 다시 처리하지 않는다.

`POST /api/campaign/{campaign_id}/turn/{turn_id}/narration`은 저장된 당시 결과의
서사만 재시도한다. 본문은 필요 없다. 완료된 턴은 모델을 호출하지 않고 기존 공개 결과를
반환한다. 캠페인과 턴이 일치하지 않으면 404, 다른 요청이 생성 중이면
409 `narration_in_progress`를 반환한다. 알 수 없는 저장 상태는
409 `narration_status_not_recoverable`로 거부하며 재생성하지 않는다.

원래 턴과 복구 요청은 180초 작업 소유권을 결과 JSON에 저장한다. 소유권 만료 후에는
중단된 작업을 다시 맡을 수 있다. 모델 호출 중 DB 쓰기 잠금은 유지하지 않으며,
저장 시 소유권 토큰을 포함한 결과 JSON 전체가 일치할 때만 교체한다.
늦게 끝난 이전 작업은 새 결과를 덮어쓰지 않는다. 모델이 180초 이상 걸리면
호출 자체는 겹칠 수 있으나 판정은 재실행되지 않고 결과 저장 소유자는 하나다.

원래 입력과 판정 원문은 턴 내부 필드로 보관하고 공개 API에서 제외한다.
이전 버전의 턴에는 원래 입력이 없으므로 빈 입력과 저장된 판정 원문을 사용한다.
현재 캠페인의 새 상태로 과거 서사를 생성하지 않는다. DB 테이블 변경은 없다.

화면은 미완료/실패 시 판정 원문과 `서사 상태 새로고침`, `서사만 다시 생성` 버튼을
표시한다. 복구 후 최신 캠페인을 재조회하여 과거 턴으로 화면 상태가 돌아가지 않게 한다.
응답 유실 시 새로고침 또는 같은 서사 복구를 재요청할 수 있다.

이는 사용자 요청에 따른 복구다. 자동 백그라운드 재생성, 모든 과거 턴의 복구 UI,
이벤트 전체 재적용, 유료 모델의 장시간 품질 검증을 완료했다는 뜻은 아니다.
