# Phaser 탐험 지도

`frontend/app/pixel-scene.tsx`는 공개된 현재 장소·NPC·은신·전투 상태를 도형으로 그린다.
인물/출구 클릭은 기존 행동 문자열을 전송하며, 서버가 현재 장소와 게임 조건을 재검증한다.
키보드 사용자는 동일한 행동 버튼으로 조작할 수 있다.

Phaser는 클라이언트에서 동적으로 로드한다. 게임 인스턴스 하나를 유지하며 서버 상태 변경 시
장면을 갱신한다. 렌더 완료 상태와 현재 React 상태가 동일할 때만 클릭을 허용하고,
작업 중이거나 서버 행동 목록에 없는 명령은 지도에서 보내지 않는다. unmount 시 게임을 해제한다.
크기 변경은 [Phaser Scale Manager](https://docs.phaser.io/phaser/concepts/scale-manager)의 FIT를 사용한다.

현재 인물의 화면 좌표는 장면 연출용이다. 게임 타일 이동·사거리·시야·엄폐·Tiled 지도는
아직 구현되지 않았으며 이 좌표를 권위 있는 전투 좌표로 사용하지 않는다.
외부 이미지 대신 직접 그린 도형을 사용하며 Phaser MIT 고지를 별도 보관한다.

브라우저 검사는 지도에서 Harlan 대화, 여관↔시장 이동, 모바일 창고→시장 클릭,
각 결말·새로고침·복원을 확인한다. 캔버스가 하나만 존재하고 새 상태 렌더를 마친 뒤 클릭하는지 검사한다.
