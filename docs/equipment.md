# 장비 선택과 실효 능력치

장비를 구매·장착하면 전투 명중/피해/방어와 은신 판정에 실제로 반영한다.
현재는 자체 시나리오의 무기·갑옷·단궁 7종이며 SRD 전체 장비, 전리품·매각·제작·내구도,
주문·클래스 숙련을 구현한 것은 아니다. 단궁은 [별도 원거리 규칙](ranged-combat.md)을 따른다.

## 장비 목록

수정치는 캐릭터의 성장한 기본 능력에 더한다. 방어구 자체의 AC 산식이나 민첩 상한 등
전체 D&D 계산을 재현하지 않으며, 기존 캐릭터 기본 AC에 명시한 차이만 적용한다.

| 장비 | 시장 가격 | 효과와 대가 |
|---|---:|---|
| 여행검 | 시작 장비 | 피해 주사위1d8, 추가 수정치 없음 |
| 중검 | 16골드 | 피해 주사위1d10, 명중−1, 피해+1 |
| 결투검 | 12골드 | 피해 주사위1d6, 명중+1 |
| 단궁 | 10골드 | 별도 원거리 슬롯, 피해1d6+기본 피해, 화살 별도 구매 |
| 여행 갑옷 | 시작 장비 | 추가 수정치 없음 |
| 강화 갑옷 | 18골드 | AC+2, 은신−2 |
| 정찰 갑옷 | 14골드 | AC−1, 은신+2 |

치명타는 현재 무기의 피해 주사위 두 개를 굴리며 피해 보너스는 한 번 더한다.
방어 태세의 AC+2는 장비 합산 후 추가된다. 밀치기·교란의 자체 고정 보너스+3은
무기 명중 보너스가 아니므로 장비로 바뀌지 않는다.

## 구매·장착·저장

- 시장에서 골드를 지불해 구매한다. 같은 장비의 중복 구매는 불가하며 자동 장착하지 않는다.
- 소유한 장비를 근접 무기/갑옷/원거리 슬롯에 장착한다. 이전 장비는 소유 목록에 남는다.
- 구매와 장착은 각각 게임시간1분. 전투 중·전투 불능 상태에서는 둘 다 불가능하다.
- 장비와 왕실 봉인 같은 퀘스트 소지품은 별도 상태다. 장비 교체가 봉인을 지우지 않는다.
- 구버전 저장에 장비 필드 전체가 없다면 여행검/여행 갑옷을 기존 기본 장비로 해석한다.
  기존 기본 판정 주사위와 보너스는 바뀌지 않는다. 잘못된 ID·미소유 장착·슬롯 불일치에는
  보너스나 소유권을 부여하지 않는다.
- 기본 능력은 `player`, 장비 소유·장착은 `equipment`, 합산 결과는 `effective_stats`로 구분한다.
  활의 능력치는 별도 `ranged_stats`이며 근접 무기의 수정치를 합산하지 않는다.
  장착할 때 `player` 값을 고쳐 누적시키지 않는다. 성장과 재장착·재투영·저장 복원에도
  현재 장비 효과가 한 번만 적용된다.
- 고정 카탈로그는 서버가 공개 목록으로 생성하며 저장이나 모델이 보낸 가격/수정치를 신뢰하지 않는다.

## 적용 범위와 검증

전투의 적 명중 판정에는 실효 AC, 플레이어 근접 명중·피해에는 실효 무기 값을 쓴다.
단궁은 `ranged_stats`의 명중·피해와 실제 화살 수량을 사용한다.
여관 은신, 후속 사건의 잠입, 성문/망루 잠입에는 같은 실효 은신 보너스를 쓴다.
설득은 이 카탈로그에서 변화하지 않는다. AI context와 화면에도 기본값과 실효값을 구분한다.

결정적 판정 검사와 실제 API 구매/장착·성장·저장/복원·동일 요청 재송신을 분리 검증한다.
브라우저에서는 시장 구매, 명시적 교체, 장비 비교·합산 표시, 원정 전투와 은신, 복원을 검사한다.
이 검증은 장비 체계 전체나 자유입력 모델 정확도·장시간 모험 완성을 뜻하지 않는다.
