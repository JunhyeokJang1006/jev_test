# 전투 회복력과 휴식

이번 능력은 현재 단일 캐릭터용 자체 규칙이다. 특정 직업 전체나 SRD의
Second Wind 규칙을 구현했다는 의미가 아니다.

- `전투 회복력 사용`: 진행 중인 전투에서 살아 있고 HP가 부족할 때,
  보조 행동과 충전 1회를 사용해 `1d10 + 현재 레벨`만큼 회복한다. 최대 HP를 넘지 않는다.
- 충전 상한은 1회다. 물약과 같은 보조 행동 예산을 사용하므로 같은 턴에 둘 다 사용할 수 없다.
- 턴 종료, 다른 전투 진입, 승리, 후퇴, 패배 치료는 충전을 돌려주지 않는다.
- 여관의 짧은 휴식(60분) 또는 긴 휴식(480분)으로 재충전한다.
  휴식 시간은 원정 기한과 세계 사건에도 반영된다.
- 짧은 휴식은 능력이 소진되었다면 HP가 가득 차거나 회복 주사위가 없어도 가능하다.
  HP가 부족하고 회복 주사위가 있을 때만 주사위 1개를 소비해 `1d8+2`를 회복한다.
- 긴 휴식은 기존과 같이 야영 보급품 1개를 소비하고 HP·회복 주사위를 회복하며,
  소진된 능력만 있어도 선택할 수 있다.
- 충전은 서버 상태에 저장한다. 재접속·중복 요청으로 회복을 중복 적용하지 않으며,
  저장 복원은 해당 저장 시점의 충전을 복원한다.

검증은 결정적 규칙 테스트, 격리 DB의 요청 재전송·저장 복원 검사와 실제 브라우저
행동 흐름을 구분한다. 이 기능만으로 전체 플레이 성공 기준을 충족하지 않는다.
