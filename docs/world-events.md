# 망루 이후의 공개 파벌 사건

원정에서 누구와 무엇을 구했는지가 다음 세계 상태를 바꾼다. 원본 §24~25·49~51의
지속 세계를 향한 첫 파벌 사건 묶음이며, 범용 시뮬레이터나 Luna World Planner 완성을
뜻하지 않는다. 현재는 엔진이 검증하는 두 개의 고정 템플릿을 사용한다.

## 수송 준비와 개입

망루 결과를 보고하면 도시 경비대·상인회·피난민 공동체의 공개 목표·보유 물자·신뢰·계획이
생긴다. 봉인 사건에서 협력한 파벌은 초기 물자와 신뢰가 높다. 보고 당시의 구조 결과를
기록해 수송 사건을 게임시간 60분 뒤로 예약한다.

시장에서 한 가지 방식으로 도울 수 있다. 행동을 마치는 시각까지 기한 안이어야 한다.

| 지원 | 조건과 비용 | 원정 선택과의 연결 |
|---|---|---|
| 경비대 호위 | 경비대 물자 1, 10분 | 문서 또는 전령·문서 모두 확보가 필요 |
| 수송 자금 | 플레이어 8골드와 상인회 물자 1, 10분 | 어느 구조 결과든 가능 |
| 자원봉사 | 돈·물자 없이 30분 | 자원이 없어도 직접 도울 수 있음 |

지원은 즉시 수송을 끝내지 않는다. 수련·이동·휴식 등 다른 일을 하는 동안에도 게임 시간이
흐른다. 전령과 문서를 모두 구했다면 지원 없이도 파벌이 협력해 수송에 성공한다.
그 외 결과에서 지원하지 않으면 수송은 지연된다. 지원 불참을 임의의 플레이어 행동이나
도덕적 결정으로 서술하지 않는다.

## 만기와 후속 결과

- 수송 성공: 상인회·피난민 물자가 늘고 지원한 파벌의 신뢰가 오른다. 시장 가격은 물약6/보급2.
- 수송 지연: 상인회 물자가 줄고 경비대·피난민의 계획이 정체/대기로 바뀐다. 가격은10/4.
- 첫 수송 예정 시각에서 60분 뒤 두 번째 정산이 진행된다. 성공했다면 구호 가격을 유지한다.
  지연됐어도 경비대가 비축 물자1을 쓰면 수송을 복구하고 가격은8/2로 회복한다.
  경비대 물자가 없으면 부족 상태가 남는다.

모든 신뢰 값은 내부0~1, 화면0~100%다. 물자와 신뢰는 서버 상태이며 AI가 변경하지 않는다.
이 사건은 플레이어 XP나 골드를 자동 지급하지 않고 원정 보상·구조 결과를 덮어쓰지 않는다.

## 상태와 검증

- 동일 만기를 여러 번 확인해도 적용은 한 번이다. 긴 휴식으로 두 기한을 넘기면 시간순으로 처리한다.
- 시작 전 저장·완료 뒤 저장·재접속·같은 요청 재전송은 원래 예약 시각과 결과·비용을 유지한다.
- GET이나 브라우저를 닫아 둔 현실 시간만으로는 세계를 진행시키지 않는다.
- 등록된 사건과 파벌만 허용한다. 잘못된 구조·대상·상태·선후 관계는 실행하지 않는다.
- 공개 문구는 검증된 상태 값으로 다시 구성한다. 임의 planner 문자열이나 내부 추가 필드는 공개하지 않는다.
- NPC에게 결과를 자동 주입하지 않는다. 현재 장소에서 대화한 NPC만 공개 공고 출처의 기억을 얻는다.
- 공개 상태를 다시 투영해도 AI에 전달되는 가능한 행동은 서버의 행동 목록과 일치해야 한다.
- 기존 저장에 사건 필드가 없으면 다음 정상 행동에서 예약한다. 과거 시간에 소급해 비용을 부과하지 않는다.

실제 두 시간 플레이의 기억 품질, 파벌의 일반 지식/위협/관계망, LLM 후보 생성·검증,
새 퀘스트·장소의 동적 생성과 무한 사건 순환은 후속 작업이다. 게임시간 두 시간을 건너뛴
테스트를 실제 두 시간 플레이 검증으로 취급하지 않는다.
